# Architecture

The CMD menu routes to project-authored scripts and separately obtained vendor tools. Functional extensions cover diagnostics, repair guidance, migration, cases, cleanup and integrity. COC-Run-Collector coordinates established collectors through a guarded output context.

COC.Core centralizes device identity, bounded paths, reparse-point rejection, session state, completion hashes, ownership-based cleanup and limited pattern redaction. Incomplete, held, changed and untracked data remain protected. Pattern redaction does not replace review for secrets.

The playbook maps symptoms to procedures/tools with offline search, navigation, decision guidance and command examples. It executes no repairs. Embedded UCU tokens provide offline styling; the console helper centers existing screens without changing tool routes.

Vendor assets, ISOs, reports and driver backups stay separate from source. Tests use disposable files; servicing/boot/migration acceptance is recorded separately.
